# Рыбалка консультант демоверсия для портфолио

Самостоятельное ограниченное демо. Три учебные карточки, два готовых комплекта и дневник в памяти вкладки. Это иллюстрация сценариев интерфейса, не полная версия продукта.

В комплекте нет исходников полного приложения, настоящих дневников, точных координат, полной базы, серверных программ, алгоритмов прогноза или API-ключей. Нет внешних зависимостей, запросов к API, localStorage и service worker. Код демо доступен посетителю браузера; защита достигается исключением ценных компонентов, а не маскировкой JavaScript.

Автор проекта Алексей Орелкин. Контакт https://freelance.ru/Niklero77

## Публикация

Создать новый публичный репозиторий без истории полного приложения. Загрузить только index.html, style.css, demo.js, README.md. Настроить GitHub Pages main /root. Проверить поиск, карточки, переключение комплекта, учебную запись и мобильный экран.

Нельзя положить это демо в новую ветку старого публичного репозитория и объявить защиту готовой: исходники сохранятся в других ветках и истории.
